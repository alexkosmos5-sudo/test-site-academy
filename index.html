О курсе

Пошаговый трек: регистрация на GitHub, создание репозитория, загрузка файлов, подключение Vercel и автоматический деплой при каждом изменении.

Программа

GitHub

Создаём репозиторий test-site-academy и загружаем файлы сайта.

Vercel

Подключаем хранилище и публикуем сайт в один клик.

Обновления

Меняем код, отправляем на GitHub — сайт обновляется сам.
