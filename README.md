# test-site-academy

Тестовый сайт академии: статическая одностраничная лендинг-страница для отработки
публикации через GitHub + Vercel.

## Состав

- `index.html` — разметка страницы
- `style.css` — стили
- `script.js` — простая интерактивность

## Публикация

Сайт публикуется через Vercel, подключённый к этому репозиторию.
Каждый push в ветку `main` обновляет опубликованную версию автоматически.
